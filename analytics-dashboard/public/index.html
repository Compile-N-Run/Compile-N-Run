SQL console

Read-only SELECT over cnr_events and the people view (id, name, email, created_at). Results are capped at 1000 rows. Timestamps are milliseconds; use datetime(ts/1000,'unixepoch').

Columns and examples

cnr_events: id, ts, client_ts, site (www|moodle), user_id, visitor_id, session_id, name, path, props (JSON), referrer, country, ua

Event names: page_view, page_engaged (props.seconds, props.scroll), lesson_read (props.on), lesson_bookmark, practice_recorded, run_code (props.lang), code_copy, ask_ai_open, ask_ai_question, search_open, interview_action, moodle_promo_click, moodle_promo_dismiss, outbound, login, logout, quiz_submit, answer_check, enrol_submit, login_click

Events are kept for 400 days. Google Analytics holds the same stream keyed by account id; this view adds names and emails from the account database.
