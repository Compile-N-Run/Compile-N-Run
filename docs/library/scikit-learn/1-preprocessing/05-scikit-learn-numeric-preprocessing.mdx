# Missing Values and Numeric Scaling

Many estimators expect finite numeric inputs, and some are sensitive to the units of each feature. Preprocessing makes those inputs usable, but its fitted statistics are part of the model. A median, mean, or variance computed from the test set shares information that should remain withheld.

An imputer fills missing entries according to a chosen rule. A scaler changes feature magnitudes. Neither operation is automatically appropriate for every column: a missing value can carry meaning, and a numeric code may identify a category rather than a measurable quantity.

## Fit on training values only

Run this independent script:

```python
import numpy as np
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler

X_train = np.array([[1., 10.], [2., np.nan], [3., 30.]])
X_new = np.array([[4., np.nan]])
imputer = SimpleImputer(strategy="median")
train_complete = imputer.fit_transform(X_train)
new_complete = imputer.transform(X_new)
scaler = StandardScaler()
train_scaled = scaler.fit_transform(train_complete)
new_scaled = scaler.transform(new_complete)
print("medians:", imputer.statistics_)
print("training means:", scaler.mean_)
print("new row:", np.round(new_scaled, 3))
assert np.isfinite(train_scaled).all()
assert np.allclose(train_scaled.mean(axis=0), 0)
```

Expect medians `[2., 20.]`, means `[2., 20.]`, and a transformed new row approximately `[[2.449, 0.]]`. The missing second value becomes the training median; the new first value lies above the training mean. Its presence does not change the learned statistics.

`fit_transform` belongs on training data. Calling it on `X_new` would learn a different transformation, so a model trained in the original coordinate system would receive inconsistent inputs. New data should pass through `transform` with the already-fitted objects.

## Understand scaling choices

`StandardScaler` subtracts a training mean and divides by a training standard deviation for each feature. It does not make a distribution Gaussian or remove outliers. Extreme values can strongly affect those statistics.

`MinMaxScaler` uses a training range, but future values can fall outside the usual zero-to-one interval. `RobustScaler` uses robust statistics and can be useful when extreme observations dominate ordinary scaling. Choose a method according to the estimator and data, then compare choices using training-side validation.

Distance-based methods and regularized linear models often need deliberate scaling. Tree splits usually do not require standardization for the same reason: they compare thresholds within a feature rather than measuring cross-feature Euclidean distance. Do not add transformations just because they are available.

## Missingness deserves inspection

Before imputing, count missing values and ask why they are missing. A sensor failure may be informative, while a blank field caused by a data import error may require repairing the source. An imputation indicator can preserve whether a value was missing, but it still needs validation and prediction-time availability.
