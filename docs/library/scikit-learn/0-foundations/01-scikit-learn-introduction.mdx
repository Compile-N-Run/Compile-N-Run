# Introduction to scikit-learn

scikit-learn provides a consistent Python interface for classical machine learning: regression, classification, clustering, preprocessing, and model selection. Its greatest practical advantage is that data preparation and estimators can share one testable workflow.

You should be comfortable with Python functions, imports, arrays, and basic tables. Review [Python](/docs/language/python) and [pandas](/docs/library/pandas) as needed. This course uses small built-in or synthetic datasets, so examples do not require downloading private data or signing up for a service. These educational results demonstrate methods, not validated decisions about real people or business operations.

## Create an isolated environment

The reference environment uses Python 3.14.4 and scikit-learn 1.9.1. The capstone's fully pinned dependencies require Python 3.12 or newer. Use a compatible supported Python release and keep the environment separate from other projects. In a new practice directory on macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install scikit-learn==1.9.1 pandas==3.0.6 joblib==1.6.0
```

On Windows, create the environment with `py -m venv .venv` and activate `.venv\Scripts\Activate.ps1` in PowerShell. Use `python -m pip` after activation so installation targets the same interpreter that runs your scripts. The [capstone](../4-unsupervised-and-production/20-scikit-learn-capstone.mdx) includes a fully pinned requirements file for its tested dependency set.

Save each lesson's main Python example in a separate `.py` file and run it with `python filename.py`. Exercise snippets continue that lesson's script unless explicitly described as replacements. This avoids accidentally using variables or fitted models left over in a notebook.

## Train a first estimator

```python
import sklearn
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
print("scikit-learn:", sklearn.__version__)
print("train/test rows:", len(X_train), len(X_test))
print("accuracy:", round(accuracy_score(y_test, predictions), 3))
```

Expect version `1.9.1`, 112 training rows, 38 test rows, and accuracy between zero and one. The training call learns from flower measurements and species labels. Prediction receives only unseen measurements. Evaluation compares predictions against labels withheld from training.

`random_state=42` makes this particular split and estimator configuration repeatable. It does not make the result universally representative or eliminate uncertainty. Trying many seeds and reporting only the best score would turn randomness into another form of selection bias.

## Build the right habit early

Separate data before learning transformations, select model settings using training-side validation, and reserve the test set for the final assessment. A high training score is not evidence of generalization. You will revisit these boundaries throughout the course because they matter more than choosing an impressive algorithm name.
