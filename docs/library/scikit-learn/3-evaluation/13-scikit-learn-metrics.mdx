# Choosing and Interpreting Metrics

A metric compresses behavior into a number. That is useful only when the number reflects the mistakes that matter. Accuracy can hide missed rare events; a good ranking score does not establish a good decision threshold; an average regression error can conceal a badly performing subgroup.

Choose the primary metric before searching model settings. Keep additional diagnostics to understand tradeoffs, and report enough context to make the number interpretable: dataset size, class proportions, split method, and the exact target definition.

## Read a confusion matrix by hand

Run this complete example:

```python
import numpy as np
from sklearn.metrics import (
    confusion_matrix, accuracy_score, precision_score,
    recall_score, f1_score, roc_auc_score, average_precision_score,
)

y_true = np.array([0, 0, 0, 1, 1, 1])
y_pred = np.array([0, 1, 0, 0, 1, 1])
scores = np.array([0.1, 0.6, 0.2, 0.4, 0.8, 0.9])
print(confusion_matrix(y_true, y_pred, labels=[0, 1]))
print("accuracy", accuracy_score(y_true, y_pred))
print("precision", precision_score(y_true, y_pred, zero_division=0))
print("recall", recall_score(y_true, y_pred, zero_division=0))
print("F1", f1_score(y_true, y_pred, zero_division=0))
print("ROC AUC", round(roc_auc_score(y_true, scores), 3))
print("average precision", round(average_precision_score(y_true, scores), 3))
```

Expect the matrix `[[2, 1], [1, 2]]`: rows are true labels and columns predicted labels in the specified order. There are two true negatives, one false positive, one false negative, and two true positives. Accuracy, precision, recall, and F1 are all two-thirds in this deliberately symmetric example.

Precision asks how many predicted positives were correct. Recall asks how many actual positives were found. F1 combines precision and recall through their harmonic mean; it does not account for true negatives and does not encode every possible error cost.

## Match labels and scores to the metric

Confusion matrices and threshold-dependent metrics use chosen labels. ROC AUC and average precision use ranking scores, such as positive-class probabilities or decision-function values. Passing hard labels to a ranking metric discards most ranking information.

Average precision summarizes a precision-recall tradeoff and is often useful when positives are rare, but its scale depends on prevalence. ROC AUC can remain high while the number of false positives at an operational threshold is unacceptable. Neither metric alone selects a threshold or proves probability calibration.

For multiclass tasks, state the averaging rule. Macro averaging weights classes equally; weighted averaging weights by support; micro averaging aggregates counts. A weighted score can conceal weak performance on a small class, so inspect per-class results too.

## Exercise and solution

Raise the threshold on `scores` from 0.5 to 0.7:

```python
stricter = (scores >= 0.7).astype(int)
print(confusion_matrix(y_true, stricter, labels=[0, 1]))
```

Expect `[[3, 0], [1, 2]]`: the false positive disappears while one positive is still missed. Precision improves here, but that is a property of these six examples, not a guarantee for arbitrary data.
