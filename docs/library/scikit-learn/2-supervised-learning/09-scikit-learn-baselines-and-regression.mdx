# Baselines and Linear Regression

Regression predicts a numeric quantity. A useful first question is whether the model improves on a simple reference, such as always predicting the training mean. Without a baseline, an error value has little context: a score can look small while offering no useful improvement.

A baseline must also be fitted only on training data. Computing the mean target from the full dataset would let the reference predictor see evaluation labels. Keep the same held-out rows and metric when comparing predefined candidates.

## Compare two simple estimators

Run this fresh synthetic-data example:

```python
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyRegressor
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, root_mean_squared_error, r2_score

X, y = make_regression(
    n_samples=300, n_features=4, n_informative=4,
    noise=12.0, random_state=42
)
X_train, X_valid, y_train, y_valid = train_test_split(
    X, y, test_size=0.25, random_state=42
)
models = {"mean baseline": DummyRegressor(strategy="mean"),
          "linear": LinearRegression()}
for name, model in models.items():
    model.fit(X_train, y_train)
    prediction = model.predict(X_valid)
    print(name, {
        "MAE": round(mean_absolute_error(y_valid, prediction), 2),
        "RMSE": round(root_mean_squared_error(y_valid, prediction), 2),
        "R2": round(r2_score(y_valid, prediction), 3),
    })
```

Expect the linear model to outperform the mean baseline on this dataset because the generator creates a linear relationship with moderate noise. That outcome demonstrates a workflow, not a general guarantee that linear regression is best for all tasks.

MAE averages absolute errors in target units. RMSE also has target units but gives larger errors more influence before taking the square root. R² compares squared errors with a reference based on the evaluation target's mean; it can be negative when predictions are sufficiently poor. It is not an accuracy percentage.

## Inspect what the model assumes

Linear regression models the target as an intercept plus weighted feature values. It can be a useful starting point when relationships are approximately additive and linear. A large coefficient does not automatically identify the most important raw feature: units and correlations influence coefficient size.

Examine residuals, defined as actual minus predicted target values. Patterns across prediction magnitude, time, or a feature can suggest that the model misses structure. Aggregate error alone can hide consistently poor behavior on part of the data.

The validation set here supports educational model comparison. In a complete project, preserve an additional untouched test set after model and preprocessing choices are finalized. Do not turn this same holdout into a repeatedly optimized leaderboard and then describe its score as independent.

## Exercise and solution

Calculate the mean residual for the linear model:

```python
prediction = models["linear"].predict(X_valid)
print("mean residual:", round((y_valid - prediction).mean(), 2))
```

It need not be exactly zero on validation data, even though an ordinary least-squares fit with an intercept has a zero-mean training residual up to numerical precision. Explain that difference before changing the estimator.
