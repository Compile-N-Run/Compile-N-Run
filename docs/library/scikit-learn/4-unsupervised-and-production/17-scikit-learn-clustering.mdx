# Clustering with K-Means

Clustering groups observations according to a model's notion of similarity. It does not discover an objective set of categories automatically. Different features, distance scales, and algorithms can produce different useful or misleading groupings.

K-means represents each cluster with a centroid and minimizes within-cluster squared distances. It works best when that geometry is a reasonable approximation. Unequal densities, elongated shapes, and strong outliers can make its clusters poorly match the structure you care about.

## Cluster a controlled example

Run this self-contained script:

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

X, generating_labels = make_blobs(
    n_samples=240, centers=3, cluster_std=0.7, random_state=42
)
workflow = make_pipeline(
    StandardScaler(), KMeans(n_clusters=3, n_init=10, random_state=42)
)
labels = workflow.fit_predict(X)
scaled = workflow.named_steps["standardscaler"].transform(X)
print("cluster counts:", np.bincount(labels))
print("silhouette:", round(silhouette_score(scaled, labels), 3))
print("agreement with generator:", round(adjusted_rand_score(generating_labels, labels), 3))
print("new assignments:", workflow.predict(X[:3]).tolist())
```

Expect three nonempty clusters and a strong separation score for these deliberately distinct blobs. The generator's labels are used only as an educational external check, not passed to `fit_predict`. In a real unlabeled dataset, such reference labels may not exist.

Cluster IDs are arbitrary. Cluster zero is not inherently the first semantic class, and another fit may permute the IDs. Adjusted Rand index compares assignments without requiring identical numeric labels. Direct classification accuracy between arbitrary cluster IDs and target codes would be misleading.

## Interpret internal scores carefully

Silhouette compares within-cluster cohesion with separation from other clusters. It needs a valid nontrivial number of labels and measures geometry under the supplied feature representation. A high silhouette score does not prove that clusters are actionable, fair, or stable over time.

This script fits and inspects the same dataset as an exploratory example. If you want to assign future observations, evaluate stability and usefulness on appropriate separate data. K-means supports `predict`, assigning new rows to learned centroids after the fitted scaler transforms them.

The explicit `n_init=10` runs several initializations. A seed makes the experiment repeatable, but other seeds and subsamples can reveal instability. Do not choose a cluster count solely because it gives a convenient narrative.

## Compare assumptions before algorithms

DBSCAN can find density-based clusters and label noise, but its distance parameters remain scale-sensitive and it does not offer the same ordinary out-of-sample `predict` interface as K-means. Hierarchical clustering answers another family of questions about nested grouping. Select an algorithm based on data geometry and intended use, not only an attractive plot.
