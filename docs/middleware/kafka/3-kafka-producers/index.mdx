# Producers

This section covers the Kafka producer from the first `send()` call to exactly-once transactions: how records are serialized, partitioned, batched, acknowledged and retried, and which settings trade latency and throughput against durability. It is for developers writing services that publish to Kafka and for anyone who has to explain why a message was lost, duplicated or delayed.
