# Kafka Connect

This section covers Kafka Connect, the framework that moves data between Kafka and databases, search indexes, object stores and SaaS systems without custom producer or consumer code. It walks from the worker and connector model through source and sink connectors, transforms and converters, production deployment, change data capture with Debezium, and error handling with dead letter queues. It is for developers integrating Kafka with the rest of their stack and for the people who will operate those pipelines.
