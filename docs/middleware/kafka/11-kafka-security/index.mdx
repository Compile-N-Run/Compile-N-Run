# Security

This section shows how to lock down a KRaft-based Kafka cluster: encrypting traffic with TLS, proving identity with SASL or mutual TLS, deciding who may do what with ACLs, keeping noisy tenants in check with quotas, handling secrets safely, and a final production checklist. It is for developers connecting services to a secured cluster and for anyone preparing a cluster for production or a security review.
