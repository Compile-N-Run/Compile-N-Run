# Projects

Six end-to-end builds that put the rest of the tutorial to work: each one starts from a business goal, designs the topics, gives you complete code and a Docker Compose file, and tells you what to watch while it runs. Pick the one closest to the system you are about to build, or work through them in order to see Kafka from the producer, consumer, Streams and Connect angles.
