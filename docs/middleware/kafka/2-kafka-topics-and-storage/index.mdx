# Topics, Partitions and Storage

This section opens up the storage layer of Apache Kafka: how topics are split into partitions, what ordering and durability a partition really promises, how replication keeps data safe, how retention and compaction decide what stays on disk, and how the broker lays bytes out in segments and indexes. It is for developers who have produced and consumed their first records and now need to design topics they can run in production.
