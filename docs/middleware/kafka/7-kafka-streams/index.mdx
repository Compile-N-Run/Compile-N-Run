# Kafka Streams

This section teaches Kafka Streams, the Java library for building applications that read from Kafka topics, transform, aggregate and join the data, and write results back to Kafka. It is for developers who have outgrown a hand-written consumer loop and need state, time windows or joins without running a separate processing cluster.
