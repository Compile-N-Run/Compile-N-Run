# Reusable Components and Custom CSS

Repeated classes are not automatically a problem. A few repeated card utilities may be easier to understand than an abstraction with many options. Extract a component when you need to keep structure, behavior, and styling synchronized across uses.

In a framework, that usually means a reusable template or component. In a plain HTML project, a small component class can be appropriate for a repeated visual pattern. Tailwind does not require every declaration to be a utility, and ordinary CSS remains available.

## Extract a deliberate action style

Keep the standard Tailwind import, then add this to `input.css`:

```css
@layer components {
  .action-link {
    @apply inline-block rounded-md bg-blue-800 px-4 py-3 font-semibold text-white;
  }
  .action-link:hover { @apply bg-blue-900; }
  .action-link:focus-visible {
    outline: 3px solid #1e40af;
    outline-offset: 4px;
  }
}
```

Use it in the starter document:

```html
<main class="mx-auto max-w-xl p-4">
  <h1 class="text-2xl font-bold">Reusable actions</h1>
  <p class="mt-4 leading-7">The component supplies a consistent visual treatment.</p>
  <a href="#exercise" class="action-link mt-6">Start the exercise</a>
  <section id="exercise" class="mt-8">
    <h2 class="text-xl font-semibold">Practice</h2>
    <p class="mt-3">Inspect which declarations come from the component.</p>
  </section>
</main>
```

Rebuild. `@apply` expands known utilities into declarations inside the component rule. The component layer is before utilities in the normal layer order, so a deliberate utility adjustment can override a component declaration without increasing selector specificity.

The class supplies appearance, while the anchor supplies navigation. If the same visual style is used on a button, that button still needs an appropriate type and actual action. A style abstraction should not blur those semantic differences.

## Keep variants explicit

If a template receives a variant such as “primary” or “secondary,” map it to complete literal class strings. Do not construct `bg-` plus a color name plus `-800` and expect the scanner to execute that expression. The next lesson explains source detection in detail.

Avoid exposing every internal spacing and color decision as a component parameter. That can create many combinations you never test. Start with a small API based on real use cases and include visible focus, disabled behavior where appropriate, and meaningful labels.

Use `@utility` when you intentionally need a custom utility that participates in Tailwind's utility and variant system. Use `@layer components` for a component style. They serve different purposes; do not assume an arbitrary custom class automatically supports every prefixed variant.

## Exercise and check

Add `px-8` to the action link's class list and inspect its computed horizontal padding. The normal utilities layer should override the component's padding declaration. Then remove the local adjustment if it is not a real design requirement.

Create a second link using the same component class and verify its hover and focus states match the first. If you change the component's outline, both uses should update together. This is the consistency benefit that justifies the extraction.
