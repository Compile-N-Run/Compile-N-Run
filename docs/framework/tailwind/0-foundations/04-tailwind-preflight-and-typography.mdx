# Preflight, Typography, and Semantic HTML

Tailwind's default import includes Preflight, a set of base styles that makes browser defaults more consistent. This affects the page before you add utility classes. Headings do not automatically retain their usual large bold appearance, lists lose their ordinary visual markers, and margins are reset.

The underlying HTML structure remains, but reset styles can affect how some assistive technologies expose it. An `h2` remains a heading for document structure even when it looks like body text. Choose the element for its role, then assign its appearance deliberately.

## Style a readable article

In the starter project, keep `@import "tailwindcss"` and replace the body contents with:

```html
<main class="mx-auto max-w-2xl px-4 py-10 text-slate-900">
  <article class="leading-7">
    <h1 class="text-3xl font-bold leading-tight">A practical learning routine</h1>
    <p class="mt-4 text-lg text-slate-700">Build understanding through small experiments.</p>
    <h2 class="mt-8 text-xl font-semibold">Three useful steps</h2>
    <ol class="mt-3 list-decimal space-y-2 pl-6">
      <li>Predict what the browser will render.</li>
      <li>Change one utility and rebuild.</li>
      <li>Explain the difference in your own words.</li>
    </ol>
    <p class="mt-6">Keep your <a href="#notes" class="font-semibold text-blue-800 underline underline-offset-4">notes</a> nearby.</p>
    <section id="notes" class="mt-8 rounded-lg border border-slate-300 p-4">
      <h2 class="font-semibold">Notes</h2>
      <p class="mt-2">A class name describes a style, not a semantic role.</p>
    </section>
  </article>
</main>
```

Rebuild and expect a limited-width article with explicit heading sizes, a numbered list, and an underlined link. `leading-7` sets line height for the article; the large title uses a tighter line height. `space-y-2` separates list children, while `mt-8` separates major sections. Use these spacing relationships consistently instead of adding unrelated values until the page looks balanced.

## Inspect the reset rather than fighting it

Preflight applies border-box sizing and normalizes many elements. Border utilities therefore need an intentional width and color, such as `border border-slate-300`. If a third-party widget expects browser defaults, inspect its assumptions and scope any restoration to that integration.

Do not solve an unstyled heading by replacing it with a paragraph that happens to look right. Likewise, an unstyled list is still a list, but restoring visible markers can be essential for readers. For lists whose markers are intentionally absent, VoiceOver may stop announcing list semantics. Retain markers when appropriate, or add `role="list"` to an intentionally markerless `ul` or `ol` when its list semantics matter. Test the result with the assistive technologies you support; the DOM structure alone is not the whole accessibility outcome.

The `prose` class is not part of the core utility set. It belongs to the optional typography plugin, which this plain-HTML course does not install. If `prose` appears to do nothing, check which packages and plugins your project actually includes.

## Exercise and solution

Remove `list-decimal` from the ordered list and compare. The ordered structure remains in HTML, but visual numbers disappear under the reset. Restore it, then change `pl-6` to `pl-8` to increase marker space.

Next, make the article title visually smaller without changing its heading level: replace `text-3xl` with `text-2xl`. Confirm the page still has one primary heading. Finally test browser zoom and a longer title; prefer wrapping over fixed-height text containers.
