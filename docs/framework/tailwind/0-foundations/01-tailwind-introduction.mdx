# Introduction to Tailwind CSS

Tailwind CSS generates a stylesheet from utility classes found in your source files. A class such as `p-6` adds padding; `text-xl` sets a text size. Combining these small rules lets you describe a component near its markup while retaining the browser's ordinary CSS layout and cascade.

Tailwind does not replace HTML semantics, implement application behavior, or make every combination accessible. You still choose meaningful elements, readable colors, and resilient layouts. Complete the [HTML](/docs/language/html) and [CSS](/docs/language/css) foundations first. This course uses plain HTML so the concepts transfer to React, Vue, server templates, or static pages.

## What you will build

The final project is a responsive workshop board with accessible navigation, course cards, and native disclosures. It has a reproducible local build and a compiled stylesheet, so viewing the finished page requires no JavaScript framework or network service.

This course targets **Tailwind CSS 4.3.0**, with matching `@tailwindcss/cli` 4.3.0. The official documentation is on the version 4 line. Version 4 uses a CSS import and CSS-first theme configuration; commands from old version 3 tutorials such as `tailwindcss init -p` are not this course's setup. The exact dependencies are pinned in the capstone so later releases do not silently change its build.

## Read a utility composition

After completing the [CLI setup](./02-tailwind-cli-setup.mdx), put this inside the example page's body:

```html
<article class="mx-auto max-w-lg rounded-xl border border-slate-300 bg-white p-6 text-slate-900">
  <h1 class="text-2xl font-bold">A focused study session</h1>
  <p class="mt-3 leading-7">Choose one exercise and explain its result.</p>
  <a class="mt-4 inline-block font-semibold text-blue-800 underline underline-offset-4"
     href="#exercise">Read the exercise</a>
</article>
<section id="exercise" class="mx-auto mt-8 max-w-lg p-6">
  <h2 class="text-xl font-semibold">Your exercise</h2>
  <p>Change the panel padding and observe its internal space.</p>
</section>
```

The article is centered within a maximum width, with a border, white surface, and explicit text styles. `mt-3` gives the paragraph separation from its heading. `inline-block` lets the link receive the intended margin behavior. These classes are ordinary CSS instructions, not a special component language.

The exact generated values come from the theme. For example, spacing utilities normally use a shared spacing variable. Changing a theme token can affect many utilities, which is useful when done deliberately and surprising when treated as a local edit.

## Use a reliable practice loop

Each later lesson assumes the starter project from the next page. Replace its body contents with the main HTML example unless a lesson specifies a smaller insertion. Keep `input.css` at its baseline import unless the lesson asks you to edit it. Run the compiler, refresh the page, and inspect the generated rule in developer tools.

Individual HTML previews on this tutorial site do not automatically compile Tailwind or combine adjacent CSS fences. Run the examples in your local starter project to see their intended styling.

## Exercise and check

Change `p-6` on the article to `p-10`, rebuild, and compare. The space inside the border should increase; the section below should retain its own padding. Then restore `p-6`. If nothing changes, investigate the build and stylesheet link before changing class specificity.
