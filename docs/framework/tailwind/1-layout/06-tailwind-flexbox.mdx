# Flexbox with Tailwind

Flexbox is useful when content primarily flows along one axis: navigation links, toolbars, or a row containing a flexible field and an action. Tailwind's flex utilities map to the same CSS axes and sizing rules you learned in the CSS course.

Apply `flex` to the parent whose direct children you want to arrange. Setting it on a child does not turn that child's siblings into flex items. `flex-col` changes the main axis; it does not permanently make `justify-*` horizontal or `items-*` vertical.

## Build a wrapping header

Use this example inside the starter page and rebuild:

```html
<header class="flex flex-wrap items-center gap-x-8 gap-y-3 border-b border-slate-300 bg-white p-4">
  <a href="#main" class="mr-auto text-xl font-bold text-blue-900">Workshop notes</a>
  <nav aria-label="Main navigation" class="min-w-0">
    <ul role="list" class="flex flex-wrap gap-x-5 gap-y-2">
      <li><a href="#sessions" class="underline underline-offset-4">Sessions</a></li>
      <li><a href="#practice" class="underline underline-offset-4">Practice</a></li>
      <li><a href="#notes" class="underline underline-offset-4">My notes</a></li>
    </ul>
  </nav>
</header>
<main id="main" class="p-4">
  <section id="sessions"><h1 class="text-2xl font-bold">Sessions</h1></section>
  <section id="practice" class="mt-8"><h2 class="text-xl font-semibold">Practice</h2></section>
  <section id="notes" class="mt-8"><h2 class="text-xl font-semibold">My notes</h2></section>
</main>
```

The brand's automatic right margin consumes spare space. The navigation moves toward the other edge when room exists, and wraps below when necessary. The list itself also wraps, so its links remain available on narrow screens without a hidden menu.

`gap-x-8` and `gap-y-3` express different horizontal and vertical spacing. Gaps remain predictable even when items wrap. `justify-between` instead distributes available space, which can create unexpectedly large separations in a wide container.

## Make growth intentional

For a row with a flexible content region and a small fixed action, use `flex-1 min-w-0` on the flexible child and `shrink-0` on the action. A shrinking text region still needs wrapping or truncation chosen according to the content's importance.

Inside a card, `flex flex-col` plus `mt-auto` on the final action can align actions across equal-height cards. The parent layout must provide extra height for the automatic margin to consume. Use `gap-*` as a minimum separation so short cards do not crowd their actions.

Do not use `order-*` or reverse-direction utilities merely to make a poor source order look correct. Visual order and keyboard reading order can diverge. Put the document in a meaningful sequence first.

## Exercise and checks

Add a fourth navigation item with a long label. Test the header at 320 pixels and with enlarged text. Every link should remain reachable and focus should follow the visible sequence.

Then replace `mr-auto` with `ml-auto` on the brand and observe the changed space distribution. Restore the original once you can explain which side consumes the free space. For multilingual layouts, consider logical auto-margin utilities such as `me-auto` rather than hard-coding left and right.
