# Grid Layouts with Tailwind

Grid expresses relationships across rows and columns. It is a strong choice for card collections, dashboards, and a main region with supporting content. Flexbox can still arrange content inside individual grid items.

Start with one column and add more only when each item has enough room. Tailwind's `grid-cols-*` utilities define tracks; `gap-*` separates them. Direct children become grid items, while nested elements keep their own layout unless you style them separately.

## Build a course collection

Replace the starter body with:

```html
<main class="mx-auto max-w-5xl p-4">
  <h1 class="text-3xl font-bold">Choose a workshop</h1>
  <div class="mt-6 grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3">
    <article class="min-w-0 rounded-xl border border-slate-300 bg-white p-6">
      <h2 class="text-xl font-semibold">HTML structure</h2><p class="mt-3">Start with meaning.</p>
    </article>
    <article class="min-w-0 rounded-xl border border-slate-300 bg-white p-6">
      <h2 class="text-xl font-semibold">CSS layouts</h2><p class="mt-3">Make room for changing content.</p>
    </article>
    <article class="min-w-0 rounded-xl border border-slate-300 bg-white p-6">
      <h2 class="text-xl font-semibold">Accessible states</h2><p class="mt-3">Support more than a pointer.</p>
    </article>
  </div>
</main>
```

Rebuild and resize. The collection has one column at small widths, two at the medium breakpoint, and three at the large breakpoint. These prefixes are minimum-width conditions, so the large rule overrides the medium column count when both apply.

Track alignment is shared across rows. Unlike a wrapped Flexbox collection, a final row with one item normally keeps the column structure established by the grid. Choose based on the relationship you want, not a belief that one layout system is always newer or better.

## Let the container choose its column count

For a collection driven by a minimum card size rather than named breakpoints, replace the grid's column classes with this literal arbitrary value:

```html
<div class="grid grid-cols-[repeat(auto-fit,minmax(min(100%,15rem),1fr))] gap-4">
  <!-- Put the same article elements here. -->
</div>
```

The inner `min(100%,15rem)` prevents the nominal minimum from exceeding a very narrow container. This is ordinary CSS Grid syntax carried through a utility. If it is unfamiliar, inspect the computed `grid-template-columns` and revisit the CSS Grid course before copying it widely.

Use `col-span-full` when an item should span the explicit grid. For a named sidebar width, an arbitrary template such as `lg:grid-cols-[minmax(0,1fr)_18rem]` can express the relationship clearly. Avoid giving the main track an accidental content-based minimum that widens the whole page.

## Exercise and solution

Add two cards and vary their paragraph lengths. First test the breakpoint layout; then test the automatic layout. Explain how each determines the final row's item widths.

Make the first card span all columns by adding `col-span-full`, and verify it remains first in the HTML. Do not use spanning or explicit placement to create a visual reading sequence that differs from keyboard navigation.
