# HTML Articles, Sections, and Containers

Not every group of elements needs the same container. Choosing a container starts with asking what the content represents and whether it belongs in the page outline.

**Prerequisites:** [Page landmarks](./0-html-landmarks.mdx). Work inside the `main` element of a workshop page.

## An article stands on its own

An `article` represents a self-contained composition that could reasonably be reused independently. Examples include a news story, a forum post, or a workshop listing with enough detail to make sense by itself.

```html
<h1>Upcoming workshops</h1>
<article aria-labelledby="repair-title">
  <h2 id="repair-title">Bicycle repair</h2>
  <p>A beginner session covering tires and saddle adjustments.</p>
  <p><a href="sessions/repair.html">Read bicycle repair details</a></p>
</article>
<article aria-labelledby="sewing-title">
  <h2 id="sewing-title">Simple sewing repairs</h2>
  <p>Practice attaching a button and repairing a small seam.</p>
  <p>Session details will be announced later.</p>
</article>
```

The second listing deliberately has no fake link. Add a real link when a real destination exists. Each article heading is `h2` because these articles sit below the page's `h1`; the article element does not reset the heading level.

## A section groups a topic

A `section` groups related content under a theme. It usually deserves a heading. Inside a detailed workshop article, preparation and schedule can be separate sections:

```html
<article>
  <h1>Bicycle repair workshop</h1>
  <section>
    <h2>Preparation</h2>
    <p>Bring a clean bicycle and wear closed-toe shoes.</p>
  </section>
  <section>
    <h2>Schedule</h2>
    <p>We begin with a demonstration, then work in pairs.</p>
  </section>
</article>
```

An article can contain sections, and a section can contain articles. The question is the relationship between the content, not a rigid recipe. Do not wrap every paragraph in a section; unnecessary structure makes a document harder to maintain.

## Neutral containers remain useful

A `div` groups flow content without adding a specific meaning. A `span` groups a portion of phrasing content. They are appropriate when you need a CSS or JavaScript hook and no more specific element describes the group.

```html
<p>Fee: <span class="price">Free</span></p>
<div class="session-actions">
  <a href="sessions/repair.html">Session details</a>
  <a href="about.html#contact">Contact the organizer</a>
</div>
```

The `price` class does not create special price semantics; it is simply a name chosen by the author. Avoid adding ARIA roles to neutral containers when an existing native element already fits the job.

## Practice and solution

Choose containers for a full event listing, its preparation subsection, and a wrapper used only to place two links side by side later.

Use `article` for the independent listing, `section` with an appropriate heading for preparation, and `div` for the visual wrapper. If the listing is only a short fragment that cannot stand alone, a simpler list item may be more suitable. Explain the content relationship before choosing the tag.
