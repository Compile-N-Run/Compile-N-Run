# HTML Responsive Images

A photo that looks good on a large display may be unnecessarily expensive on a small one. Responsive image markup gives the browser options while preserving a useful fallback.

**Prerequisites:** [Images and alternatives](./0-html-images-and-alt-text.mdx). Prepare three exports of the same photo and crop: `workshop-480.jpg`, `workshop-960.jpg`, and `workshop-1440.jpg`, with actual widths of 480, 960, and 1440 pixels. Store them in `images`.

## Describe real candidates

Add this rule in the head to establish the displayed image width:

```html
<style>
  .session-photo { display: block; width: 100%; max-width: 48rem; height: auto; }
</style>
```

Then put the image in the body:

```html
<img class="session-photo"
     src="images/workshop-960.jpg"
     srcset="images/workshop-480.jpg 480w,
             images/workshop-960.jpg 960w,
             images/workshop-1440.jpg 1440w"
     sizes="(max-width: 48rem) 100vw, 48rem"
     width="1440" height="960"
     alt="Participants inspect a bicycle together.">
```

Each `w` descriptor states the resource's actual width, not your preferred display width. `sizes` estimates how much horizontal space the image will occupy. Here it is approximately the viewport width on small screens and at most 48rem on larger screens. Default body margins mean the small-screen estimate is slightly generous, which is acceptable for this introductory example.

`sizes` does not apply layout; CSS does. If your design later puts the photo in a half-width column, update the estimate. The browser uses candidates, expected display size, device pixel density, and its own selection behavior to choose a source. Do not assume a specific viewport always downloads one exact file.

## Change the crop with picture

Sometimes a small screen needs a close crop rather than a smaller version of the wide scene. Create a square `workshop-close.jpg` and use:

```html
<picture>
  <source media="(max-width: 40rem)" srcset="images/workshop-close.jpg">
  <img class="session-photo" src="images/workshop-960.jpg"
       width="960" height="640"
       alt="A participant adjusts a bicycle saddle.">
</picture>
```

`picture` lets the browser choose a source according to conditions. The required `img` provides fallback and the image's text alternative. Keep the alternative accurate for every crop. Because the crops have different ratios, this simple version may shift space as the selected file loads; a production design should reserve the correct space for each condition.

## Inspect rather than guess

Reload with Developer Tools open and inspect image requests. Caching can keep an already downloaded larger candidate available even after resizing. In the console, selecting the image and checking its `currentSrc` property can reveal the resource currently used; this is a diagnostic step, not required application JavaScript.

## Practice and solution

A photo displays at 24rem on wide screens. Change the full estimate to `sizes="(max-width: 24rem) 100vw, 24rem"` and the CSS maximum width to `24rem` too. Keep candidate descriptors equal to the actual export widths. Verify the image stays sharp and does not overflow; selection remains the browser's decision.
