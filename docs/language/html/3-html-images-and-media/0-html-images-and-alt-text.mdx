# HTML Images and Alternative Text

An image needs a resource URL and an alternative when its visual content conveys information. The right alternative depends on what the image does in this particular page.

**Prerequisites:** [File paths](../1-html-text-and-links/2-html-links-and-paths.mdx). Place a photo you are allowed to use in `images/workshop.jpg`. For the first example, export it at 1200 by 800 pixels or change the dimensions to match your file.

## Add an informative image

```html
<figure>
  <img src="images/workshop.jpg"
       width="1200" height="800"
       alt="Two participants practice adjusting a bicycle saddle.">
  <figcaption>Participants work in pairs during the repair session.</figcaption>
</figure>
```

`src` locates the file. `width` and `height` supply dimensions and let the browser reserve space before the resource finishes loading. They should describe the image's actual proportions. They do not optimize the image file's byte size.

The alternative text explains relevant visual information. A caption is visible to everyone and can supply context, credit, or an explanation. It does not automatically remove the need for suitable `alt` text. Avoid repeating exactly the same long sentence in both places.

At its default size, a large image may overflow a narrow viewport. A minimal CSS rule can make it shrink while preserving its ratio:

```html
<style>
  img { max-width: 100%; height: auto; }
</style>
```

Place that style element in the document's head. You will explore layout and styling in the CSS course; the next HTML lesson covers selecting an appropriately sized source file.

## Choose alternatives by purpose

If an image is purely decorative and conveys no information beyond nearby text, use `alt=""`. An absent `alt` is different from an intentionally empty alternative and can lead to unhelpful announcements such as a filename.

If an image is the only content of a link, its alternative should communicate the destination or action:

```html
<a href="index.html">
  <img src="images/logo.png" alt="Community Workshop home"
       width="120" height="60">
</a>
```

For charts or diagrams, a short alternative may identify the subject while nearby prose or a data table provides the detailed information. Do not try to fit a complex dataset into one enormous attribute.

## Loading and failures

Use `loading="lazy"` for suitable images farther down a long page, but avoid delaying the main image people see immediately. Lazy loading is a browser hint, not a guarantee that an image loads at one exact scroll position.

If an image does not appear, inspect the Network panel. Check filename case, extension, and the path relative to the current document. An alternative is not a replacement for fixing a broken resource.

## Practice and check

Describe three images: a workshop activity photo, a decorative flourish, and a logo linking home. Your solutions should provide relevant visual information, an empty alternative, and a destination label respectively. Temporarily rename the photo file to test the broken-image case, then restore it. Read the surrounding content without the photo and check whether important information remains available.
