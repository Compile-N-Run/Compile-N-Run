# HTML Quotations, Code, and Dates

Some text carries meaning beyond an ordinary paragraph. HTML provides elements for quotations, code, dates, and other patterns. Use them when they describe the content accurately, rather than adding tags to every word.

**Prerequisites:** [Headings](./0-html-headings-and-paragraphs.mdx) and [character escaping](../0-html-foundations/3-html-attributes-and-escaping.mdx).

## Distinguish quoted material from your own words

Use `blockquote` for a quotation that stands apart from the surrounding text. Give visible attribution, because the optional `cite` attribute does not automatically display a source link:

```html
<figure>
  <blockquote>
    <p>I arrived with a loose saddle and left knowing how to adjust it.</p>
  </blockquote>
  <figcaption>Sam, a fictional workshop participant</figcaption>
</figure>
```

This example is invented, so the attribution says so. For a real quotation, identify its actual source and respect permission and quotation limits. The `cite` element names a work, such as a book or article; it is not a general-purpose wrapper for a person's name.

A short quotation inside a sentence can use `q`. Browsers generally supply quotation marks for that element, so do not add another pair blindly. Avoid using `blockquote` merely to indent content; indentation is a CSS concern.

## Show code faithfully

`code` identifies a code fragment, while `pre` preserves whitespace and line breaks. Combine them for a block sample:

```html
<p>Use the <code>title</code> element to name the browser tab.</p>
<pre><code>&lt;title&gt;Workshop schedule&lt;/title&gt;
&lt;h1&gt;Workshop schedule&lt;/h1&gt;</code></pre>
```

The angle brackets still need escaping inside `pre` and `code`. Those elements do not disable HTML parsing. Keep indentation inside a `pre` intentional because it becomes part of the displayed sample. Later, CSS can handle long-line overflow without deleting meaningful whitespace.

## Supply an unambiguous date

Readers can see a friendly date while software gets a standardized value:

```html
<p>The session is on <time datetime="2027-04-17">17 April 2027</time>.</p>
<p>Doors open at <time datetime="09:30">9:30 a.m.</time> local time.</p>
```

The `datetime` attribute describes the visible date or time; it does not create a calendar booking, update an event automatically, or convert time zones. Give a time zone in visible event information when visitors may join from different regions.

For abbreviations, expand unfamiliar terms in nearby prose first. A `title` attribute can provide supplementary information, but a hover tooltip is not a reliable way to deliver essential instructions to every input method.

## Practice and solution

Write a paragraph announcing a session on 8 May 2027 and show the literal code `<p>Hello</p>` beneath it.

```html
<p>Join us on <time datetime="2027-05-08">8 May 2027</time>.</p>
<pre><code>&lt;p&gt;Hello&lt;/p&gt;</code></pre>
```

Check that the date is readable without inspecting attributes and that the code appears as text rather than becoming a new paragraph.
