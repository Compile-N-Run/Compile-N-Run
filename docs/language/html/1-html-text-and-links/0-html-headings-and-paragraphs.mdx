# HTML Headings and Paragraphs

Readers often scan headings before reading a page. Screen reader users can also navigate by heading. A useful outline makes the document easier to understand regardless of its visual design.

**Prerequisites:** [Attributes and escaping](../0-html-foundations/3-html-attributes-and-escaping.mdx). Create `session.html` using the document template and put the following examples in its body.

## Build an outline before styling

Use a single descriptive `h1` for this page, followed by `h2` headings for major sections and `h3` headings for subsections:

```html
<h1>Bicycle repair session</h1>
<p>Learn to make everyday adjustments to your bicycle.</p>

<h2>Before you arrive</h2>
<h3>Bring your bicycle</h3>
<p>Clean the frame so you can handle it comfortably.</p>
<h3>Check your booking</h3>
<p>Bring the confirmation provided by the organizer.</p>

<h2>During the session</h2>
<p>We will practice checking tire pressure and adjusting a saddle.</p>
```

The two `h3` headings belong to “Before you arrive.” Returning to `h2` starts the next major section. Heading levels express relationships, not font sizes. Do not jump from `h1` to `h4` because the browser's default `h4` looks smaller. CSS can change appearance without damaging the outline.

A section element does not automatically reset heading levels. Write the hierarchy explicitly. One main `h1` is a clear convention for these pages; the goal is a comprehensible outline rather than counting tags without considering the content.

## Choose paragraphs and emphasis

A paragraph contains a related thought. Start another paragraph when the subject changes. Pressing Enter twice in source code does not reliably create a new paragraph; ordinary whitespace is collapsed in normal text rendering.

```html
<p><strong>Bring a helmet</strong> for the outdoor practice.</p>
<p>You may borrow tools, but bring <em>your own</em> water bottle.</p>
```

`strong` expresses importance; `em` adds stress emphasis. Avoid selecting them solely to produce bold or italic styling. Their semantic meaning may be useful even when a particular assistive technology does not announce it through a noticeable voice change.

Use `br` when a line break belongs to the content, such as an address or a poem. Do not insert repeated `br` elements to create margins between sections. Likewise, empty paragraphs are not spacing tools.

## Practice and solution

A draft page has the headings “Workshop,” “Preparation,” “Equipment,” and “Contact.” Equipment is part of Preparation; Contact is another main section. Mark up the outline and add a sentence to each section.

The heading levels should be:

```html
<h1>Workshop</h1>
<h2>Preparation</h2>
<h3>Equipment</h3>
<h2>Contact</h2>
```

Read only those headings aloud. The nesting should still make sense without the paragraphs or default text sizes. Then inspect the page at increased browser zoom: the content should remain understandable when lines wrap differently.
