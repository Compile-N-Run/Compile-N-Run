# HTML Lists and Description Lists

Lists express relationships that a series of manually typed bullets cannot. A browser can expose the list and its items to assistive technology, and you can later change its presentation without rewriting the content.

**Prerequisites:** [Headings and paragraphs](./0-html-headings-and-paragraphs.mdx). Add these examples to `session.html`.

## Decide whether order matters

An unordered list groups related items whose sequence is not essential:

```html
<h2>Bring these items</h2>
<ul>
  <li>A bicycle</li>
  <li>A helmet</li>
  <li>A water bottle</li>
</ul>
```

An ordered list represents a sequence. Changing the order of repair steps could change the outcome:

```html
<h2>Check tire pressure</h2>
<ol>
  <li>Read the pressure range printed on the tire.</li>
  <li>Attach a suitable pump with a pressure gauge.</li>
  <li>Inflate within the tire manufacturer's recommended range.</li>
  <li>Disconnect the pump and replace the valve cap.</li>
</ol>
```

Each item is an `li` inside its list. Do not type `1.`, `2.`, and `3.` into separate paragraphs and expect equivalent semantics. The browser generates ordered-list numbering and keeps it consistent when you insert an item.

## Nest inside an item

A sublist is part of its parent item, so place it before that item's closing tag:

```html
<ul>
  <li>Protective equipment
    <ul>
      <li>Helmet</li>
      <li>Closed-toe shoes</li>
    </ul>
  </li>
  <li>Water bottle</li>
</ul>
```

The nested `ul` is not a sibling of the outer `li`. Indent the source to make that ownership visible. List items can contain paragraphs and other appropriate content; they are not limited to a single word or sentence.

## Describe name-value relationships

A description list pairs terms or names with descriptions:

```html
<dl>
  <dt>Duration</dt>
  <dd>90 minutes</dd>
  <dt>Experience</dt>
  <dd>No previous repair experience needed</dd>
  <dt>Tools</dt>
  <dd>Provided during the session</dd>
</dl>
```

Use `dt` for the term and `dd` for its description. A description list can suit a glossary or a small set of facts. It is not a universal substitute for a table: use a table when readers need to compare values along both rows and columns.

## Practice and check

Create a packing list with a nested list of two optional items. Then create an ordered three-step arrival procedure and a description list for location and start time.

A correct solution uses `ul` for packing, nests the optional list inside its containing `li`, uses `ol` for the arrival sequence, and pairs each `dt` with a meaningful `dd`. Remove the default bullet styling in Developer Tools only if you already know CSS: the structure should remain a list in the DOM. Styling does not decide the content's relationship.
