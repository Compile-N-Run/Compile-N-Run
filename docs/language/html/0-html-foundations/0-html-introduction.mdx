# HTML Introduction

HTML describes the meaning and structure of a web page. A heading tells readers what a section covers; a link connects resources; a form collects input. These meanings help browsers and assistive technologies present content in useful ways.

**Prerequisites:** No programming knowledge. You need a text editor and a web browser. This course builds toward a small community workshop website, with exercises you can run on your own computer.

## What HTML does

HTML is a markup language. You surround content with elements instead of writing an algorithm. CSS controls appearance and layout. JavaScript adds programmable behavior. A useful page can work with HTML alone: links navigate, form controls accept input, and disclosure widgets open without a framework.

A browser reads HTML and constructs a document tree called the DOM. It also gives elements default presentation: headings appear prominent and links are usually underlined. Those defaults are a starting point, not the meaning of the elements. Choose a heading because it introduces content, not because you want large text.

## Make your first page

Create a folder named `workshop-site`. In a plain-text editor, save the following as `index.html`, using UTF-8 encoding. Open the file in your browser.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Community Workshop</title>
</head>
<body>
  <h1>Community Workshop</h1>
  <p>Learn practical skills with your neighbors.</p>
  <p>Our first session is about repairing a bicycle.</p>
</body>
</html>
```

You should see one large heading and two separate paragraphs. The browser tab should say “Community Workshop.” Change the second paragraph, save, then refresh the browser. Saving changes the file; refreshing makes the browser read it again.

The file works locally because the browser can read it from disk. Other people cannot access that file through a public URL until you put it on a web server. HTML also cannot save a visitor's registration to a database by itself. Later lessons distinguish the browser's responsibilities from a server's.

## Avoid early confusion

A file named `index.html.txt` is a text file with the wrong extension. Enable filename extensions in your file manager if the browser displays source text unexpectedly. Use a code editor, not a word processor that adds document formatting. Check that you opened the same file you edited when changes seem to disappear.

Do not install a framework to finish this example. Understanding the document that a framework eventually produces will make future tools easier to use.

## Practice and check

Add a second heading named “Who can attend?” and a paragraph explaining that beginners are welcome. Keep the existing main heading.

A suitable addition before `</body>` is:

```html
<h2>Who can attend?</h2>
<p>Beginners are welcome. Bring your curiosity.</p>
```

Check that the new heading appears below the introduction and the tab title remains unchanged. You have edited visible content without changing document metadata.
