# Introduction to CSS

CSS, or Cascading Style Sheets, controls the presentation of a document: its colors, typography, spacing, and layout. HTML supplies the structure and meaning. A heading remains a heading when you change its size, and a styled link still needs a destination. If elements, attributes, or document structure are unfamiliar, start with the [HTML course](/docs/language/html).

You need a text editor and a browser. The examples use plain HTML and CSS, without a package manager or framework. By the end, you will build a responsive study dashboard and diagnose layout problems with developer tools.

## Create your first page

Create a folder named `css-practice` with two files. Put this complete document in `index.html`:

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My learning notebook</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main class="notebook">
    <h1>My learning notebook</h1>
    <p>Today I am learning how CSS rules work.</p>
    <a href="#practice">Jump to practice</a>
    <section id="practice">
      <h2>Practice</h2>
      <p>Change one declaration, save, and refresh.</p>
    </section>
  </main>
</body>
</html>
```

Put the following in `styles.css`, then open `index.html` in your browser:

```css
body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  color: #172033;
  background-color: #edf2f7;
}

.notebook {
  max-width: 42rem;
  margin: 2rem auto;
  padding: 1.5rem;
  background-color: white;
  border: 2px solid #cbd5e1;
}

h1 {
  color: #234e9b;
}
```

You should see a white reading panel on a pale background and a blue heading. The `h1` selector identifies which elements receive the declarations inside its braces. A declaration combines a property such as `color` and a value such as `#234e9b`, separated by a colon.

The stylesheet path is relative to the HTML file. If you put the CSS in a `css` subfolder, change the link to `href="css/styles.css"`. Keep the HTML and stylesheet filenames lowercase to avoid problems on servers with case-sensitive paths.

## Use a small feedback loop

Change `padding: 1.5rem` to `padding: 3rem`, save the stylesheet, and refresh. The panel gains internal space. Change it back and inspect the heading using your browser's developer tools. The Styles panel should show your `h1` rule. Edits made inside developer tools are usually temporary; copy a successful change into your source file.

An external stylesheet is useful because multiple pages can share it. A `style` element inside the HTML head also works for small experiments. An element's `style` attribute affects that element directly, but scattering presentation throughout HTML makes later changes harder. This course uses the external file consistently.

If nothing changes, check that the link is inside the head, the files are saved, and the browser loaded the expected CSS file. Do not start adding stronger selectors until you know the stylesheet loaded.

## Exercise and checks

Add a second paragraph inside the practice section. Make every paragraph dark green using one new rule, without changing the HTML.

```css
p {
  color: #14532d;
}
```

All three paragraphs should change, while the heading remains blue. Disable the declaration in developer tools and observe the paragraphs return to the body's text color. That difference previews inheritance, which you will study shortly.

For each later lesson, start from a fresh copy of these two files and replace the stylesheet with that lesson's CSS unless it explicitly says to append a rule. Replace the body's existing contents with each lesson's main HTML example unless a specific insertion point is stated. This avoids nesting or duplicating the starter's main element. The page's individual HTML previews do not load a separate CSS fence; use your local files to run paired examples.
