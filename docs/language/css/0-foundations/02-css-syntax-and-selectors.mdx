# CSS Syntax and Selectors

A CSS rule has a selector and a declaration block. The selector matches elements; each declaration assigns one property. The browser evaluates matching rules together, rather than executing them as sequential programming statements.

```css
.notice {
  padding: 1rem;
  border: 2px solid #234e9b;
}
```

Whitespace makes this easier to read but does not create the structure: braces, colons, and semicolons do. Include the final semicolon so adding another declaration cannot accidentally join two values. Use `/* comments */` for CSS comments; JavaScript's `//` is not a CSS comment.

## Match the right elements

Use the [starter document](./01-css-introduction.mdx), replace the contents of its main element with this HTML, and add the CSS below to `styles.css`:

```html
<section class="lesson-list">
  <h1>Today's lessons</h1>
  <article class="lesson lesson--featured">
    <h2>Selectors</h2>
    <p>Find the element you mean.</p>
    <a href="#practice" data-kind="exercise">Try the exercise</a>
  </article>
  <article class="lesson">
    <h2>The cascade</h2>
    <p>Understand competing rules.</p>
    <a href="#practice">Read the notes</a>
  </article>
  <p id="practice">Practice area</p>
</section>
```

```css
.lesson { padding: 1rem; }
.lesson--featured { background: #dbeafe; }
.lesson > h2 { margin-top: 0; }
.lesson p { line-height: 1.7; }
[data-kind="exercise"] { font-weight: 700; }
a:hover { text-decoration-thickness: 0.2em; }
h1, h2 { color: #172033; }
```

The first card has a blue background, both cards have padding, and the exercise link is bold. The direct-child selector `.lesson > h2` matches a heading directly inside a lesson. The descendant selector `.lesson p` also matches paragraphs nested deeper inside it.

A type selector such as `p` targets an element name. A class selector begins with a dot and can be reused. An ID selector such as `#practice` targets an ID that should be unique within the document. IDs are useful for links and labels, but class selectors usually make component styling easier to override.

A comma creates a selector list: `h1, h2` means either heading type. A space describes ancestry: `h1 h2` means an `h2` inside an `h1`, which is a very different and usually unintended structure. `.lesson.lesson--featured` requires both classes on the same element.

Pseudo-classes describe conditions or states. `:hover` matches pointer hover; `:focus-visible` helps style keyboard focus. Pseudo-elements, such as `::before`, represent a part of an element rather than another HTML element. Generated decoration is useful, but essential instructions should live in real HTML.

## Prefer stable relationships

Avoid selectors that depend on an entire page hierarchy, such as `body main section article div p`. Adding a wrapper can break them or change which elements match. Name a meaningful component instead. Also avoid using `:nth-child()` to encode permanent meaning such as “the second item is urgent”: content order changes.

An invalid property value is normally ignored, allowing other valid declarations to work. A malformed selector can invalidate its rule. When a rule has no effect, inspect matching before adjusting specificity; [the cascade lesson](./03-css-cascade-and-specificity.mdx) explains that next step.

## Exercise and solution

Make only the paragraph immediately following each card heading bold. Do not add classes or affect the practice paragraph.

```css
.lesson > h2 + p {
  font-weight: 700;
}
```

The `+` combinator matches the next element sibling. Verify that inserting another element between a heading and its paragraph stops the match. This deliberate experiment distinguishes adjacent siblings from arbitrary descendants.

Further reading: [W3C selector relationships and syntax](https://www.w3.org/TR/selectors-4/#combinators).
