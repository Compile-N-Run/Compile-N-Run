# CSS Foundations

Learn how stylesheets connect to HTML, how selectors match, and how the browser resolves competing or missing declarations. Work through the lessons in order and use a fresh pair of practice files for each experiment.

- [Introduction to CSS](./01-css-introduction.mdx)
- [CSS Syntax and Selectors](./02-css-syntax-and-selectors.mdx)
- [The CSS Cascade and Specificity](./03-css-cascade-and-specificity.mdx)
- [Inheritance and Browser Defaults](./04-css-inheritance-and-defaults.mdx)

Each lesson includes a practical example, a focused exercise, and a way to check the result. Start with [Introduction to CSS](../0-foundations/01-css-introduction.mdx) if you are new to the course.
