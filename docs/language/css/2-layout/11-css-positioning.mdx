# CSS Positioning

Positioning is useful for badges, anchored decorations, and persistent controls. It is usually the wrong first tool for laying out an entire page: taking every section out of flow makes text growth and screen-size changes much harder to handle.

`position: static` is the default. Relative positioning leaves the element's original space in normal flow, then visually offsets its box. Absolute positioning removes the element from normal flow and places it using a containing block. A positioned ancestor often establishes that containing block; transforms and other properties can also do so.

## Anchor a badge to its card

Add this HTML to the starter page and these rules to your stylesheet:

```html
<article class="course-card">
  <span class="badge">New</span>
  <h1>Layout fundamentals</h1>
  <p>Understand boxes before arranging a whole page.</p>
</article>
<p>This paragraph remains below the card.</p>
```

```css
body { padding: 1rem; font: 1rem/1.6 system-ui, sans-serif; }
.course-card {
  position: relative;
  max-width: 30rem;
  padding: 3.5rem 1rem 1rem;
  border: 1px solid #94a3b8;
}
.badge {
  position: absolute;
  inset-block-start: 0.75rem;
  inset-inline-end: 0.75rem;
  padding: 0.2em 0.6em;
  color: #14532d;
  background: #dcfce7;
  border-radius: 0.25rem;
}
```

The badge sits near the card's upper corner. The card's top padding reserves room because the absolute badge contributes no height to normal flow. Remove `position: relative` from the card and observe the badge's reference change. Restore it before continuing.

Prefer a flex or grid row if the badge text can become several lines: an in-flow badge automatically reserves its actual size. Absolute placement is appropriate when overlap is intentional and tested.

## Fixed and sticky elements

A fixed element is typically positioned relative to the viewport and stays there while the document scrolls. An ancestor with a transform can instead become its containing block. Fixed banners and buttons can cover content, especially when zoomed; reserve room and test the smallest supported viewport.

Sticky positioning preserves the element's flow space and adjusts its position within scrolling constraints. Try this on a heading in a long article:

```css
.article-heading {
  position: sticky;
  top: 0;
  background: white;
  padding-block: 0.5rem;
}
```

At least one relevant inset, such as `top`, is needed for the sticky effect. The parent must provide room to move. An ancestor's overflow settings can make it the relevant scroll container, even when that is not the scrolling region you expected. A sticky element also remains constrained by its containing block; it does not float freely across the entire document.

## Exercise and checks

Move the badge to the lower inline-start corner. Change the card padding to reserve space below its text:

```css
.course-card { padding: 1rem 1rem 3.5rem; }
.badge {
  inset-block-start: auto;
  inset-inline-end: auto;
  inset-block-end: 0.75rem;
  inset-inline-start: 0.75rem;
}
```

Reset the old insets explicitly so both opposing edges do not accidentally remain active. Test a two-line heading and 200% zoom. If the badge covers content, change to an in-flow design rather than piling on offsets.
