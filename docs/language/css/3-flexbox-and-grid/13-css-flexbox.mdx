# Flexbox Fundamentals

Flexbox arranges a group primarily along one axis. It is useful for navigation, controls, and rows of cards whose sizes should respond to available space. Set `display: flex` on the parent; its direct children become flex items.

The main axis follows `flex-direction`. With `row` in an English horizontal document, it runs left to right. The cross axis is perpendicular. With `column`, those axes switch, so `justify-content` is not permanently a horizontal alignment property.

## Start with three items

Use a fresh starter document and replace its stylesheet with the CSS below:

```html
<div class="topics">
  <article class="topic"><h2>HTML</h2><p>Structure and meaning.</p></article>
  <article class="topic"><h2>CSS</h2><p>Presentation and responsive layout.</p></article>
  <article class="topic"><h2>JavaScript</h2><p>Interactive behavior.</p></article>
</div>
```

```css
* { box-sizing: border-box; }
body { margin: 0; padding: 1rem; font: 1rem/1.6 system-ui; }
.topics {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  align-items: stretch;
}
.topic {
  flex: 1 1 14rem;
  min-inline-size: 0;
  padding: 1rem;
  border: 1px solid #94a3b8;
  background: #eff6ff;
}
```

At wide widths the cards share a row. When three preferred widths plus gaps no longer fit, items wrap. Each row distributes its own available space: if the last row has one card, that card can expand across the row. Choose [Grid](./15-css-grid.mdx) when you want shared columns across rows.

## Read the flex shorthand

`flex: 1 1 14rem` sets growth, shrinkage, and basis. The basis supplies a starting main size. A grow factor distributes positive free space; it is not a promise that a factor of two makes an item twice as wide overall. The existing base sizes still matter.

A shrink factor participates when a line has insufficient space. Shrinkage is weighted by the item's base size, and minimum-size constraints can stop it. `min-inline-size: 0` allows these cards to shrink beyond their automatic content minimum; their content must still be made wrappable when necessary.

`flex: 0 0 auto` is useful for an item that should keep its content-based size. Avoid applying it indiscriminately to large content, because it can force overflow. `flex: 1` is convenient for equal flexible shares, but use an explicit shorthand when teaching or debugging the intended basis.

## Align the available space

`justify-content` distributes leftover space along the main axis. `align-items` aligns items across each line. `align-self` overrides that cross-axis alignment for one item. `align-content` controls distribution of multiple flex lines when the container has extra cross-axis space; it does not center the contents of a single card.

Use `gap` for predictable spacing between items. `space-between` distributes remaining space and may create much larger gaps on wide screens.

## Exercise and checks

Change `align-items` to `flex-start` and make one description longer. The cards should stop sharing equal stretched heights within a row. Restore `stretch`, then set the second card to `flex-grow: 2` and widen the viewport. It receives a larger share of free space, but is not necessarily twice the full width of its neighbors.
