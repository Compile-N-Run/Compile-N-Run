# CSS Grid Fundamentals

Grid arranges direct children in rows and columns. Choose it when relationships across both dimensions matter: a dashboard, aligned card collection, or main-and-sidebar layout. Flexbox works well inside individual grid items; the two layout systems complement each other.

A grid track is the space between neighboring grid lines. Columns and rows are tracks. Grid items can be automatically placed or explicitly span multiple tracks.

## Create a two-column collection

Use a fresh starter page with this content and stylesheet:

```html
<div class="course-grid">
  <article><h2>HTML</h2><p>Write a meaningful document.</p></article>
  <article><h2>CSS</h2><p>Build resilient layouts.</p></article>
  <article><h2>JavaScript</h2><p>Add interactive behavior.</p></article>
  <article><h2>Projects</h2><p>Combine what you learned.</p></article>
</div>
```

```css
* { box-sizing: border-box; }
body { margin: 0; padding: 1rem; font: 1rem/1.6 system-ui; }
.course-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;
}
.course-grid > article {
  min-inline-size: 0;
  padding: 1rem;
  border: 1px solid #94a3b8;
  background: #eff6ff;
  overflow-wrap: anywhere;
}
```

The four cards form two aligned columns and two rows. Rows arise automatically because only columns are explicitly defined. Their heights are content-based; a taller card can increase its whole row's height.

The `fr` unit represents a share of available track space after other sizing constraints are considered. `1fr 2fr` requests one share and two shares, not exactly one-third and two-thirds of the entire container regardless of gaps and minimums.

`minmax(0, 1fr)` supplies an explicit zero minimum. A bare `1fr` has an automatic minimum that can be influenced by content. The zero minimum helps avoid a long item forcing a column wider than intended, but content still needs its own wrapping or overflow policy.

## Make columns emerge from available space

Replace the columns declaration with:

```css
.course-grid {
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 15rem), 1fr));
}
```

The grid fits as many minimum-sized columns as it can and distributes leftover room. `min(100%, 15rem)` prevents the nominal minimum from exceeding the container on very small screens. Without that inner `min()`, a container narrower than `15rem` could overflow.

`auto-fit` collapses empty repeated tracks, letting occupied tracks expand. `auto-fill` retains those empty tracks. Compare them in a wide container with only two cards; the difference is easier to see than with many cards filling every possible column.

## Control placement carefully

To make the first card span the whole explicit grid, add `grid-column: 1 / -1`. The lines are numbered; `-1` refers to the last line of the explicit grid. Explicit placement can change visual order, so keep the DOM order logical and check keyboard navigation for interactive cards.

## Exercise and checks

Use the automatic column pattern, add five more cards, and vary description lengths. At narrow widths there should be one column; wider views should gain columns without new media queries. Make the first card span all columns and confirm later cards still follow it.
