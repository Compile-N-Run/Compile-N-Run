# CSS Colors and Backgrounds

Color establishes hierarchy, but a successful interface still works when someone cannot distinguish two hues. Pair visual differences with text, shape, or another signal: an error needs an explanation, and a selected navigation item should not depend on a subtle color shift alone.

## Describe colors deliberately

Hexadecimal colors such as `#234e9b`, `rgb(35 78 155)`, and `hsl(219 63% 37%)` are useful ways to express roughly similar blue tones. RGB describes channel intensities. HSL exposes hue, saturation, and lightness, which can be convenient when experimenting. HSL lightness is not a measurement of perceived brightness or contrast.

An alpha component makes a color translucent:

```css
.notice {
  background-color: rgb(35 78 155 / 0.1);
  color: #172033;
}
```

The final appearance depends on what is behind the notice. Setting `opacity: 0.5` on the whole notice is different: it makes the complete element, including its text and descendants, translucent. Use an alpha background when only the surface should be transparent.

## Create a decorated panel

Add this HTML to your practice page and its styles to `styles.css`:

```html
<section class="study-panel">
  <h1>A small step every day</h1>
  <p>Choose one lesson and finish its exercise.</p>
  <a href="#plan">View the study plan</a>
</section>
<section id="plan">
  <h2>Your plan</h2>
  <p>Start with selectors, then investigate the cascade.</p>
</section>
```

```css
body {
  margin: 0;
  padding: 1rem;
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  color: #172033;
}
.study-panel {
  padding: 2rem;
  border: 1px solid #93c5fd;
  border-radius: 1rem;
  background-color: #eff6ff;
  background-image: linear-gradient(120deg, #eff6ff, #dbeafe);
  box-shadow: 0 0.5rem 1rem rgb(15 23 42 / 0.08);
}
a { color: #174398; text-underline-offset: 0.2em; }
```

You should see a pale gradient panel with dark text and a subtle shadow. The solid background remains useful if the image declaration is unavailable. Gradients are CSS images, which is why they belong in `background-image`. Border radius rounds a box's corners; it does not automatically clip every overflowing child.

## Images and contrast

For a decorative photograph, `background-size: cover` fills the area but may crop the image. `contain` preserves the entire image and may leave unused space. Background URLs in an external stylesheet are resolved relative to that stylesheet, not the HTML document.

A background image has no HTML alternative text. Use an HTML `img` when the image conveys content, and provide an appropriate `alt`. Never put essential text only into an image or generated background.

Check contrast against the actual adjacent background, including every part of a gradient. WCAG's minimum text contrast is generally 4.5:1, or 3:1 for qualifying large text; do not estimate it from how bold a font looks. The [W3C contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) explains the thresholds and exceptions. Underlines also help distinguish links from ordinary text.

## Exercise and solution

Create a warning variation with an amber surface, a stronger border on the inline-start edge, and an explicit warning label in HTML:

```html
<p class="warning"><strong>Reminder:</strong> Save before closing the editor.</p>
```

```css
.warning {
  padding: 1rem;
  color: #713f12;
  background: #fef3c7;
  border-inline-start: 0.3rem solid #92400e;
}
```

Verify the message still makes sense with colors disabled. This is a useful first check before building [interactive states](../5-production/21-css-states-and-forms.mdx).
