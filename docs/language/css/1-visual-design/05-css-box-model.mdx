# The CSS Box Model

Every visible element participates in layout through boxes. A useful first model has four regions: content, padding around the content, a border around the padding, and an outside margin separating the box from neighbors. A background normally paints through the padding and behind the border; the margin is transparent.

## Measure an actual box

In the [practice document](../0-foundations/01-css-introduction.mdx), put this element inside the body and replace the stylesheet with the following rules:

```html
<div class="card">A measured card</div>
```

```css
.card {
  width: 240px;
  padding: 20px;
  border: 4px solid #234e9b;
  margin: 24px;
  background: #dbeafe;
}
```

With the default `box-sizing: content-box`, the declared width applies to the content region. The outer border-box width is `240 + 20 + 20 + 4 + 4 = 288px`. Horizontal margins add another `48px` to the space this example needs. Open the browser's box-model diagram to inspect each region rather than estimating by eye.

Now add:

```css
.card { box-sizing: border-box; }
```

The border box is now `240px` wide; the content area is `192px` after subtracting padding and borders. Margins remain outside. Border-box simplifies fitting cards inside a layout because the width includes their decorative edges. For extremely small widths, padding and borders still impose a minimum physical size; border-box is not permission to fit unlimited padding into zero space.

A common project default applies this behavior consistently:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

## Choose the right kind of space

Use padding when the space belongs inside a component's background or clickable surface. Use margin to separate a component from surrounding content. Use `gap` between children of a flex or grid container, as you will practice in [Flexbox](../3-flexbox-and-grid/13-css-flexbox.mdx).

In ordinary block layout, adjacent vertical margins can collapse. A paragraph with `margin-bottom: 24px` followed by one with `margin-top: 16px` commonly has a `24px` gap, not `40px`. Parent and child margins can also collapse in certain circumstances. Padding, borders, and layout modes affect that behavior. Flex and grid item margins do not collapse with one another.

Prefer logical properties when expressing document-relative spacing: `padding-inline` handles both inline sides, and `margin-block` handles both block sides. In a typical horizontal English page, inline corresponds to left/right and block to top/bottom. This vocabulary adapts more naturally to other writing modes.

## Exercise and solution

Make a card whose border box is at most `30rem`, with `1rem` padding, a `2px` border, and centered horizontal placement. It must also fit a narrow parent.

```css
.card {
  box-sizing: border-box;
  width: 100%;
  max-width: 30rem;
  padding: 1rem;
  border: 2px solid #234e9b;
  margin: 1rem auto;
}
```

Give the body `padding: 1rem` so the card has an outside gutter. Check at both narrow and wide widths: the card should fit its parent's content area and stop growing at `30rem`. If it still overflows, inspect its children for fixed widths or unbreakable text; those are [sizing and overflow](../2-layout/10-css-sizing-and-overflow.mdx) problems.

Further reading: [W3C box regions](https://www.w3.org/TR/css-box-3/#box-model).
