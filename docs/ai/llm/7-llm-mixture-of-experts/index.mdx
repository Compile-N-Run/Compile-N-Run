# Mixture of Experts

This section explains how sparse Mixture-of-Experts (MoE) models such as Mixtral, DeepSeek-V3, Qwen3 and gpt-oss store hundreds of billions of parameters but use only a small fraction of them per token, how their routers decide where each token goes, and what it takes to implement, train and serve them. Read it after the Transformer and pretraining sections if you want to read an MoE config.json with confidence or build an MoE layer yourself.
