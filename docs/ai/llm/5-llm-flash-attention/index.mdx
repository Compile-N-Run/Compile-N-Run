# FlashAttention and Efficient Attention

This section explains why attention is limited by memory traffic rather than arithmetic, how FlashAttention computes exact attention tile by tile with online softmax, what changed in FlashAttention-2, -3 and -4, and which approximate and distributed attention methods take over when even an exact fused kernel is not enough. It is for readers who want to read the kernel papers, use the right attention backend in PyTorch, Hugging Face or vLLM, and reason about long-context cost.
