# Quantization and Efficient Models

This section explains how LLMs are shrunk to fit cheaper hardware: integer and low-bit float formats, post-training quantization methods such as GPTQ and AWQ, GGUF files for llama.cpp and Ollama, FP8 and FP4 on modern GPUs, KV cache compression, and small models built for phones and laptops. Read it if you want to run or serve a model with less memory, or need to choose between the quantized checkpoints you find on Hugging Face.
