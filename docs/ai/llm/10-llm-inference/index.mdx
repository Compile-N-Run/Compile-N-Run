# Inference and Decoding

This section explains what happens after training: how a model turns a prompt into tokens, why generation is limited by memory bandwidth rather than compute, and how serving engines such as vLLM, SGLang, TensorRT-LLM and llama.cpp use KV caching, paging, batching and speculation to serve many users cheaply. Read it if you deploy models, tune a serving stack or want to understand where inference latency and cost come from.
