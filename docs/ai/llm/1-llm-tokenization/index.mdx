# Tokenization and Embeddings

Before a language model sees a single word, a tokenizer turns text into integer ids and an embedding matrix turns those ids into vectors. This section explains both steps in depth, from implementing byte-level BPE yourself to reading a model's tokenizer files and avoiding the bugs that tokenization causes in real systems.
