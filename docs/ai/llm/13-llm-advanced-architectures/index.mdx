# Advanced Architectures

This section goes beyond the standard text-only decoder: models that see images, recurrent state space and linear-attention layers, hybrids that mix them with attention, reasoning models that spend compute at test time, diffusion language models that write in parallel, and multi-token prediction. It is for readers who already know the Transformer block and want to read the papers and config.json files behind the newest models.
