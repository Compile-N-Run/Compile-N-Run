# Contact Us

We'd love to hear from you. Whether you've found an error in a tutorial, have a topic you'd like us to cover, want to contribute, or just have a question, there are several ways to reach us.

## Email

For general questions, feedback, corrections, or content suggestions, email us at:

**[feedback@compilenrun.com](mailto:feedback@compilenrun.com)**

We read every message and aim to respond within a few business days.

## Report an Issue or Contribute

Compile N Run is developed in the open. If you've found a mistake in a guide or want to suggest an improvement, you can open an issue or pull request on our GitHub repository:

**[github.com/Compile-N-Run/Compile-N-Run](https://github.com/Compile-N-Run/Compile-N-Run)**

## About the Maintainer

Compile N Run is maintained by an independent software engineer. You can find more about the maintainer's work at **[yuyangwang.org](https://www.yuyangwang.org/)**.

## What We'd Love to Hear About

- Errors, typos, or outdated information in any tutorial
- Topics or technologies you'd like us to add
- Suggestions for improving existing guides
- Broken links or other site issues
- Feedback on how we can make the site more useful for learners

Thank you for helping us make Compile N Run better for everyone.
