Practice and check your work

Open an exercise with a pointer, Enter, or Space.

1. Review the document structure

Inspect this page's HTML. Find the main content, the navigation label, and the heading that names each section. Then add a fourth course card in your own copy.

Check: Keep one main element, use an h3 for the new card title, and give its link a meaningful local destination.

2. Stress-test the card layout

Replace a card title with a longer phrase. Resize the browser to 320 CSS pixels, then widen it and zoom to 200%. Try another font in the body rule.

Check: Text wraps without clipping, cards remain inside the page gutters, and every link has a visible keyboard focus indicator.

3. Separate native behavior from application state

The links navigate, these disclosures open, and the checklist can reset without JavaScript. Decide how you would save the checklist across visits.

Check: Explain that CSS controls presentation; persistent checklist data would require application logic and storage. This demo intentionally does not save it.
